Neste perfil, compartilho projetos acadêmicos e exercícios que conectam programação, análise de dados e fundamentos de infraestrutura.

## 🚀 Projetos que representam minha jornada

### 01 · Ciência de Dados | Estudos EBAC

[**Explorar os notebooks →**](https://github.com/vittorbeckham/projetos-ebac)

Exercícios e projeto didático de concessão de cartões de crédito, com etapas de exploração e preparação de dados, classificação com Random Forest e avaliação por acurácia e matriz de confusão. O repositório também reúne exercícios de arrays, operações vetorizadas e seleção de dados com NumPy.

**Tecnologias:** Python · Jupyter Notebook · NumPy · pandas · Seaborn · Matplotlib · scikit-learn  
**Contexto:** atividades orientadas de formação em Ciência de Dados.

---

### 02 · Redes de Computadores | Bragato Mix

[**Conhecer o projeto →**](https://github.com/vittorbeckham/projeto-lan-grupo-RVH-)

Projeto acadêmico desenvolvido em equipe na **Faculdade Serra Dourada**, no curso de **Análise e Desenvolvimento de Sistemas**, que representa a infraestrutura de um comércio real no Cisco Packet Tracer. Inclui distribuição de IPv4 por DHCP, topologia, documentação e evidências de testes de ping entre equipamentos.

**Conhecimentos:** redes locais · DHCP · gateway · conectividade IPv4 · documentação técnica  
**Entrega:** simulação em Packet Tracer, relatório e evidências.

---

### 03 · Sistemas Operacionais | Processos Linux

[**Ver o estudo →**](https://github.com/vittorbeckham/trabalho-linux-processos-)

Trabalho acadêmico desenvolvido em dupla na **Faculdade Serra Dourada**, no curso de **Análise e Desenvolvimento de Sistemas**, sobre o comportamento dos processos do Minecraft Java Edition no Ubuntu. A análise aborda hierarquia de processos, uso de CPU e memória, prioridades e efeitos de sinais de controle.

**Conhecimentos:** Linux · PID e PPID · processos · sinais · monitoramento de recursos  
**Entrega:** documentação do experimento, comandos e evidências em PDF.

---

### 04 · Python & Automação | Vittor.bot

[**Explorar o código →**](https://github.com/vittorbeckham/Vittor.bot)

Projeto acadêmico da **Faculdade Serra Dourada**, no curso de **Análise e Desenvolvimento de Sistemas**: bot para a plataforma Highrise, com funções de interação e movimentação. O código reúne exemplos de integração com SDK, tarefas assíncronas e organização de funcionalidades em módulos.

**Tecnologias:** Python · asyncio · Highrise Bot SDK  
**Foco de aprendizado:** automação e programação orientada a eventos.

## 🔭 Construindo agora

**VIGIA AI** é um projeto acadêmico desenvolvido em equipe na **Faculdade Serra Dourada**, no curso de **Análise e Desenvolvimento de Sistemas**, voltado à proposta de monitoramento inteligente. A base atual reúne uma interface de acesso em HTML e CSS, backend em Python com Flask e infraestrutura com MySQL, Nginx e Docker Compose.

O projeto segue em desenvolvimento: a integração completa de autenticação e os recursos de monitoramento e IA fazem parte das próximas etapas. O repositório é privado.
